# Collaborators

Collaborators contribute regularly and have triage or write access. This is
distinct from maintainers, who own releases and final review.

| Name         | GitHub   | Focus            | Open to work |
|--------------|----------|------------------|--------------|
| (open)       |          |                  |              |

## Becoming a collaborator

1. Land a few solid pull requests that follow `AGENTS.md`.
2. Help with issue triage and reviews.
3. A maintainer proposes access; maintainers confirm by consensus.

## Expectations

- Follow the conventions in `AGENTS.md`.
- Keep changes scoped and reviewable.
- Respect the security policy in `SECURITY.md`.
